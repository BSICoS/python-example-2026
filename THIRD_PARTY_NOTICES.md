## Sleep Wave Analysis Toolbox

This repository contains a Python port and adaptation of components from the Sleep Wave Analysis Toolbox for MATLAB.

Original authors: Armand Mensen, Brady Riedner, and Giulio Tononi  
Original repository: https://github.com/Mensen/swa-matlab  
Source revision: commit `6e5f295`  
Archived software: https://doi.org/10.5281/zenodo.14985  
Original license: GNU General Public License version 2.0

The Python port is located primarily in `src/lib/swa`. These files have been modified and translated into Python for integration into the EEG feature-extraction pipeline.
